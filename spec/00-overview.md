# 00. 概要と原則

Web ベースのチェスゲーム「chess-web」の技術設計書。本 spec 群は、AI エージェントが人間の追加判断なしに全機能を自律実装できることを目標に書かれている。曖昧さを残さないため、型定義・スキーマ・プロトコル・完了条件をすべて具体値で記述する。

## 1. 目的とスコープ

高品質なシングルページのチェスゲームを構築する。サーバーは不要で、静的ホスティングのみで動作する。

**スコープ内:**

- ローカル対人戦(同一端末で 2 人が交互に操作)
- CPU 戦(Stockfish、難易度 4 段階、先手/後手選択可)
- 全標準ルール(キャスリング、アンパッサン、プロモーション、チェック、チェックメイト、ステイルメイト、各種ドロー)
- 状態永続化(リロード・切断後も対局を完全復元)
- 投了、新規対局、手番履歴表示、捕獲駒表示

**スコープ外:**

- オンライン対戦、観戦、チャット
- 持ち時間(クロック)
- 棋譜のインポート/エクスポート UI(内部では PGN を使うが、UI は提供しない)
- 待った(undo)— 将来拡張として設計上は妨げないが、実装しない

## 2. コア原則

1. **コンシューマーゲーム品質** — コンソールゲームの水準の滑らかさ・応答性を目指す。すべての操作に即時の視覚フィードバックがあり、アニメーションは 60fps を維持する。CPU 思考中も UI は一切ブロックしない。
2. **モバイルファースト & 1:1 盤面** — タッチ操作(二回タップ方式)を第一級の入力とする。盤面は常に正確な 1:1 アスペクト比を保ち、モバイル縦画面からデスクトップまでシームレスにスケールする。
3. **状態永続化** — 毎手番後に LocalStorage へ保存し、リロード・クラッシュ・誤操作によるタブクローズ後も、対局状態と履歴を損失なく復元する。
4. **伝統的美学** — 高級な木製チェスセットを想起させる、オーソドックスで上品なビジュアル。木目調の配色、Staunton 様式の駒、セリフ体のタイポグラフィを、モダンな CSS で洗練させて表現する。
5. **完全なチェスルール** — ルール判定は自前実装せず、すべて chess.js に委譲する。UI はその合法手情報の投影に徹する。

## 3. 技術スタック

| 領域 | 技術 | 選定理由 |
| --- | --- | --- |
| ビルド | Vite 8(lightningcss) | 導入済み。高速 HMR と CSS Modules ネイティブサポート |
| フレームワーク | SolidJS 1.9 | fine-grained reactivity により盤面 64 マスの差分更新が仮想 DOM なしで最小コストになる |
| 言語 | TypeScript(strict) | 導入済み。型で状態遷移の不正を防ぐ |
| スタイリング | CSS Modules | スコープ化された CSS。デザイントークンは CSS カスタムプロパティで共有 |
| ルールエンジン | chess.js(^1.x) | 合法手生成・特殊手・終了判定・FEN/PGN を網羅する事実上の標準 |
| 思考エンジン | stockfish(npm、lite single-thread WASM) | Web Worker で非同期実行。SharedArrayBuffer 不要ビルドを選び静的ホスティング互換にする |
| UI プリミティブ | @kobalte/core | 導入済み。Dialog をプロモーション選択・ゲーム終了・新規対局に使用 |
| アイコン | lucide-solid | 導入済み |
| テスト | Vitest 4 + @solidjs/testing-library + happy-dom | 導入済み |

追加が必要な依存は `chess.js` と `stockfish` の 2 つのみ([07-implementation-plan.md](07-implementation-plan.md) M1 参照)。

## 4. 用語集

| 用語 | 意味 |
| --- | --- |
| FEN | 局面 1 つを表す文字列表記(Forsyth–Edwards Notation) |
| PGN | 対局全体(手順)を表すテキスト表記。永続化と復元に使用 |
| SAN | 1 手の代数表記(例: `Nf3`, `O-O`, `exd5`)。履歴表示に使用 |
| UCI | チェスエンジンとの通信プロトコル(Universal Chess Interface)。手は `e2e4`/`e7e8q` 形式 |
| Square | `"a1"`〜`"h8"` のマス座標文字列 |
| Skill Level | Stockfish の強さ調整オプション(0–20) |

## 5. 実装時の言語規約

本 spec は日本語で書かれているが、**実装成果物はすべて英語**とする(CLAUDE.md 準拠)。コード内コメント、ログ・エラーメッセージ、テスト名、コミットメッセージ、README を含む。UI に表示する文言も英語とする(例: "Checkmate — White wins", "New Game")。
